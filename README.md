# Помощник по сделкам OKX в Telegram

Вы сообщаете боту, что вошли в сделку, — он отвечает планом и ведёт сделку до закрытия. Сам бот не торгует.

## Что умеет

**Вход** — форма (кнопка «➕ Новая сделка / анализ» внизу чата) или команда:

```
/in aero short 0.553 x20 10          монета, шорт/лонг, вход, плечо, маржа $
/in aero short 0.553 x20 10 стоп 0.57   со своим стопом
```

Ответ: стоп по графику (за ближайшим уровнем 15м, не ближе обычного шума), цель 1 и цель 2 у уровней 1ч/4ч, суммы в долларах, риск/прибыль, ликвидация (и предупреждение, если она раньше стопа), совпадает ли вход с сетапом сканера, предупреждения: Hammer, перепроданность, мало места до поддержки, вход вдогонку, против тренда 4ч, скорое открытие биржи у токенов акций.

**Сопровождение** (проверка раз в минуту):
- 🔒 прошли 1R — перенести стоп в безубыток;
- 🎯 цель 1 — закрыть 50%, стоп в безубыток; 🎯🎯 цель 2 — закрыть остаток;
- 📉 новый нижний максимум 1ч (для лонга — минимум) — подтянуть стоп;
- ⏳ цена близко к стопу — напоминание не двигать стоп;
- ⚠️ Hammer/Star против сделки, RSI(15м) у края, 🔔 открытие биржи для токенов акций;
- 🛑 стоп задет — итог сделки в долларах.

**Другие команды:** `aero` или `/analyze aero` — разбор монеты · `/status` · `/stop aero 0.56` · `/out aero` · `/menu`.
Под каждой сделкой есть кнопки «Статус», «Стоп», «Закрыть».

## Как работает

GitHub Actions запускает бота цепочкой: каждый запуск ~4.5 минуты держит связь с Telegram и следит за сделками, потом начинается следующий. Поэтому ответы приходят за секунды; раз в ~5 минут бывает пауза до минуты, пока запуск сменяется. Открытые сделки хранятся в памяти Actions (кэш) между запусками.

Можно использовать того же Telegram-бота, что и у сканера: сканер только отправляет сообщения, а помощник читает ваши команды.

## Установка

1. **Секреты** — Settings → Secrets and variables → Actions:
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (можно те же, что у сканера).
2. **Права** — Settings → Actions → General → Workflow permissions → **Read and write permissions**.
3. **Форма** — Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/docs` → Save.
   Через 1–2 минуты форма будет по адресу `https://fozilb.github.io/by_trade_assistant/`.
4. **Проверка** — Actions → Assistant → Run workflow → галочка «Только отправить приветствие» → Run.
   В Telegram придёт приветствие и кнопки внизу.
5. **Запуск** — Actions → Assistant → Run workflow без галочек. Дальше цепочка идёт сама.

Форма отправляет данные только если открыта кнопкой **внизу чата** (не по ссылке). Если кнопки нет — напишите боту `/menu`.

Важно: ручной запуск с галочкой во время работы цепочки может её прервать — расписание восстановит её за 10 минут.

Репозиторий должен быть **публичным**, чтобы Actions был бесплатным. Ваши сделки в репозиторий не попадают и в логах не пишутся.

## Настройки

`assistant_config.py` — стоп, цели, безубыток, предупреждения. `config.py` и `shortsetup.py` — правила сетапа (те же, что у сканера), список токенов акций `STOCK_TOKENS`.
